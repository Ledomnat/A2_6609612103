What I Built

สำหรับ Assignment 1 ผมได้สร้าง Website หน้าเดียว เพื่อแนะนำตัวเอง โดยใช้แค่ HTML และ CSS

ภายใน Website ประกอบด้วยข้อมูลเกี่ยวกับตัวผม วิธีการสร้าง Website และสิ่งที่ได้เรียนรู้จากการทำงานนี้

Client and Server

เมื่อเปิด Website จากเครื่องของผมเอง Web Browser จะทำหน้าที่เป็น Client โดย Browser จะอ่านไฟล์ HTML และ CSS แล้วนำมาแสดงผลเป็น Website

ไม่มี Server เนื่องจากสามารถเปิดไฟล์ HTML(index.html) จากเครื่องของตัวเองได้โดยตรง

How I Built It

ขั้นแรกผมวางโครงสร้างของ Website และกำหนดหัวข้อที่ต้องการเขียน จากนั้นจึงสร้างโครงสร้างของหน้าเว็บด้วย HTML และใช้ CSS ในการตกแต่ง Website

Tools I Used

Reflection

Challenges

ปัญหาที่พบคือการทำความเข้าใจว่า HTML และ CSS ทำงานร่วมกันอย่างไรโดยแยก Files รวมถึงการจัดตำแหน่งและตกแต่งองค์ประกอบต่าง ๆ ผมแก้ปัญหาโดยทดลองแก้ไขโค้ดทีละส่วน และตรวจสอบผลลัพธ์ผ่าน Web Browser

What I Learned

ผมเข้าใจ HTML มากขึ้นว่า HTML ใช้สำหรับสร้างโครงสร้างและเนื้อหาของเว็บไซต์ ส่วน CSS ใช้สำหรับกำหนดรูปแบบ สี ขนาด และการจัดวางองค์ประกอบต่าง ๆ และ Website เล็กๆแต่ใช้เวลาทำนานมาก

Future Improvements

หากมีโอกาสพัฒนาต่อ ผมอยากเพิ่มข้อมูลเกี่ยวกับ Projects ที่เคยทำ และปรับปรุงการออกแบบให้สวยงามและใช้งานง่ายมากขึ้น
